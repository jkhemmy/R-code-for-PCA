# PCA Analysis of LA-ICP-MS Elemental Data

This repository contains the R code, dataset, and figures associated with the principal component analysis (PCA) of Cu, Zn, and Fe concentrations measured by LA-ICP-MS.

## Analysis

PCA was performed using standardised mean whole-lumbar Cu, Zn, and Fe concentrations from 18 biological replicates.

PCA scores were visualised according to:

- Tissue preparation
- Operator
- Sex
- Experimental cohort

The first two principal components accounted for 78.63% of the total variance.

## Files

- `PCA_analysis.R` — R script used to perform the PCA and generate figures.
- `MasterTable.xlsx` — dataset used for the analysis.
- `figures/` — PCA figures generated using the R script.
